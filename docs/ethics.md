# Data ethics

- **Check with Dr Das / IRB** whether this project needs ethics review or an exemption before collection starts.
- **Public data only.** No private groups, DMs, or content behind logins beyond normal API access.
- **Platform terms.** Use official APIs; follow rate limits and terms of service; note them in `research_log.md`.
- **Pseudonymise.** Hash usernames on ingestion with a secret salt kept outside the repository.
- **No re-identification in the paper.** Paraphrase social media posts rather than quoting verbatim (verbatim quotes are searchable). FAA comments are a public government record but contain names — do not name private individuals in the paper.
- **Data storage.** Raw data stays out of any public repository. Share only aggregated results and, if allowed, IDs for re-collection.
- **Deleted content.** If a platform's terms require it, remove content that has since been deleted.
